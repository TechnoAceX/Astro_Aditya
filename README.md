# 🔮 Astro Aditya

**Astro Aditya** is a beautifully designed astrology web app that offers users insightful information about zodiac signs, horoscopes, and spiritual guidance. Built using HTML, CSS, and JavaScript, it serves as a simple, responsive, and aesthetically pleasing platform for those seeking cosmic wisdom.

🌐 **Live Demo:** [Click Here to Visit](https://technoacex.github.io/Astro_Aditya/)

---

## ✨ Features

- ✅ Clean and responsive UI
- ♈ Overview of all 12 zodiac signs
- 🌟 Daily horoscope & traits section
- 🌙 Planetary insights and zodiac compatibility
- 📱 Mobile-friendly layout

---

## 🛠️ Tech Stack

- **HTML5** – Page structure  
- **CSS3** – Styling and responsiveness  
- **JavaScript** – Interactive elements  
- **GitHub Pages** – Deployment
